# Raven Hsieh portfolio

Visual prototype for a multilingual English-calligraphy portfolio.

## Included

- Fixed minimal navigation with EN / 中文 / 日本語 switching
- Split-screen hero with generated material study artwork
- Interactive motion-study cards and pointer tilt
- About, index, selected work, commissions, and contact sections
- Identity / Editorial work filters
- Clickable work cards with animated ink burst and dynamic `project.html?project=...` detail pages
- `mailto:` commission links prefilled with `xiejingru1999@outlook.com` and a project brief
- Responsive layout with reduced-motion support

## Replace the placeholders

- Replace `assets/studio-signal.png` with the final hero image if desired.
- Replace the `portrait-placeholder` block in `index.html` with a portrait image.
- Replace the three `.motion-card` blocks with actual GIF `<img>` elements when the assets are ready.
- Update Instagram, Behance, and GitHub URLs in the footer.
- Add more project detail records in the `details` object inside `script.js`.
- `assets/feather-fall.png` is the small falling-feather sprite; replace it with final scanned feather art if needed.

## GitHub Pages

This is a static site. Upload the contents of this folder to a GitHub repository, then enable GitHub Pages from the repository's Settings using the main branch and `/root` folder.
